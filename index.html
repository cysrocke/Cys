팝업 수첩

산리오·위글위글 팝업 소식과 상품을 모아 보는 앱

지금 카카오톡 안에서 열려 있어요.
오른쪽 아래(또는 위) 메뉴에서 “다른 브라우저로 열기 → Safari”를 눌러 다시 열어주세요. 카카오톡 안에서는 설치가 안 돼요.
홈 화면에 설치하기

설치 순서

  1. 위 버튼을 누르고 허용(또는 다운로드)을 눌러요.
  2. “프로파일이 다운로드됨”이 안 뜨고 다운로드만 됐다면: 주소창 왼쪽의 ⬇︎ 다운로드 아이콘 → popup-sucheop.mobileconfig를 눌러요.
  3. “프로파일이 다운로드됨”이 뜨면 설정 앱을 열어요.
  4. 맨 위 프로파일이 다운로드됨 → 오른쪽 위 설치.
  5. 아이폰 암호 입력 → 한 번 더 설치 → 완료.
  6. 홈 화면에 생긴 팝업 수첩 아이콘을 눌러요.

알아두기

  1. 설치 중 “서명되지 않음”이 보여도 괜찮아요. 홈 화면 아이콘 하나만 추가해요.
  2. 지우려면 설정 → 일반 → VPN 및 기기 관리 → 팝업 수첩 → 프로파일 제거.

아이폰 Safari 전용이에요.
